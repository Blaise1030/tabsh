# File Pane Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Cmd/Ctrl-clicking a path in a terminal opens that file in a pane beside the terminal, where you can preview it or make a quick edit and save it safely. URLs open in a new browser tab.

**Architecture:** The daemon (`src/main.rs`) gets a file API: resolve a path against a tab's shell directory, read it, read its raw bytes, and save it. A save only goes through if the file hasn't changed since it was read. The page (`web/src/pages/app/index.astro`) detects links with a pure matcher (`web/src/app/links.ts`) and loads the pane module (`web/src/app/file-pane.ts`, with CodeMirror 6) on first use, through an Astro-bundled bridge script. The bundle is copied into `src/app-assets/`, embedded by `build.rs`, and served by the daemon at `/_astro/…`, so the daemon's own copy of the page (used by Safari) works too.

**Tech Stack:** Rust 2024, axum 0.8, tokio, rusqlite. Astro 7 with Vite. CodeMirror 6 (`codemirror`, `@codemirror/*`), `marked`. xterm.js 5.5 from CDN. Tests run with `node --test` on Node 24.

**Spec:** `docs/superpowers/specs/2026-10-03-file-pane-design.md`

## Global Constraints

- **Preconditions:**
  - The in-progress Safari / daemon-served-page work must be committed before Task 1: `build.rs`, `src/app.html`, `LOCAL_NAME`, `APP_CSP`, `local_app`, the `build` script copying `app.html`, and the CI `app.html` check.
  - Work happens on branch `feat/file-pane`, which already exists and holds the spec commit.
- **Size limits:**
  - Text `content` is returned only for files up to **2 MB** (`TEXT_LIMIT_BYTES = 2 * 1024 * 1024`).
  - `/api/files/raw` serves up to **50 MB** (`RAW_LIMIT_BYTES = 50 * 1024 * 1024`).
  - A 413 is returned above either limit.
- **Version stamp:** `"<mtime nanoseconds since epoch>-<size>"`.
- **Text:** valid UTF-8 and no NUL byte. `eol` is `"crlf"` if the first line break is `\r\n`, otherwise `"lf"`.
- **Auth:**
  - Every `/api/files*` route goes through the existing `guard`, so it needs the token.
  - `/_astro/{name}` is a public static route, like `/sounds/{*path}`. If the security-hardening plan (`docs/superpowers/plans/2026-10-03-security-hardening.md`) has landed, add `/_astro/` to whatever exemption it gives `/sounds/` and `/app/`.
- **Keys:**
  - Cmd-click on Mac and Ctrl-click elsewhere (`isMac` already exists in the page).
  - ⌘/Ctrl-S saves and ⌘/Ctrl-E toggles Edit/Preview. Esc focuses the terminal.
  - ⌘/Ctrl-W is never bound.
- **Settings keys:**
  - `paneWidth`: a number, fraction of `#workspace`, clamped to 0.2–0.8, default 0.5.
  - `editor`: one of `vscode` | `cursor` | `zed`, default `vscode`.
  - Both are validated in `loadSettings` like the existing keys.
- **Narrow screens:** below 800px, the pane covers the terminal (CSS media query).
- **CSP:** `img-src data: blob:` and `frame-src blob:` in both `web/public/_headers` (`/app/*`) and `APP_CSP`. Nothing else is loosened.
- **Code style:**
  - The daemon stays in one file (`src/main.rs`) with tests in its `mod tests`. Don't split it.
  - Comments are short and explain why, matching the existing code.
- **Checks:**
  - Daemon: `cargo fmt --check && cargo clippy --all-targets --locked -- -D warnings && cargo test --locked`
  - Web: `cd web && npm test && npm run build`

## Review Focus

1. **A path whose file has an unsaved edit in the pane, then changes in vim.** Saving must return a 409, not overwrite. The `save_file` stale-version test in Task 3 covers this, plus the manual vim check in Task 10.
2. **CRLF files.** Saving through CodeMirror, which normalises line endings to `\n`, must write `\r\n` back. A `toDisk` / `fromDisk` round-trip test in Task 6 covers it.
3. **Paths with spaces or Unicode in the URL query** (`my notes/ü.md`) must round-trip through `encodeURIComponent` and axum's `Query`. A `files.test.ts` URL test in Task 6 covers it, plus a `resolve_path` Unicode case in Task 1.
4. **Saving through a symlink** must keep the symlink and change the file it points to. The `save_file` symlink test in Task 3 covers it.
5. **Executable scripts** must stay executable after a save. The `save_file` permissions test in Task 3 covers it.

```rust
fn resolve_path_handles_relative_home_symlinks_and_git_prefixes() {
    let dir = scratch();
    let base = dir.join("proj");
    std::fs::create_dir_all(base.join("src")).unwrap();
    std::fs::write(base.join("src/main.rs"), "fn main() {}").unwrap();
    std::fs::write(base.join("ü notes.md"), "hi").unwrap();
    std::os::unix::fs::symlink(base.join("src/main.rs"), base.join("link.rs")).unwrap();
    let real = std::fs::canonicalize(base.join("src/main.rs")).unwrap();

    assert_eq!(resolve_path(&base, &dir, "src/main.rs"), Some(real.clone()));
    assert_eq!(resolve_path(&base, &dir, "./src/../src/main.rs"), Some(real.clone()));
    assert_eq!(resolve_path(&base, &dir, "~/proj/src/main.rs"), Some(real.clone()));
    assert_eq!(resolve_path(&base, &dir, "link.rs"), Some(real.clone()));
    assert_eq!(resolve_path(&base, &dir, "a/src/main.rs"), Some(real.clone()));
    assert_eq!(resolve_path(&base, &dir, "b/src/main.rs"), Some(real));
    assert!(resolve_path(&base, &dir, "ü notes.md").is_some());
    assert_eq!(resolve_path(&base, &dir, "~"), Some(std::fs::canonicalize(&dir).unwrap()));
    assert_eq!(resolve_path(&base, &dir, "missing.rs"), None);
    assert_eq!(resolve_path(&base, &dir, "a/missing.rs"), None);

fn file_kind_by_extension_then_content() {
    let p = |s: &str| PathBuf::from(s);
    assert_eq!(file_kind(&p("x"), b"", true), FileKind::Dir);
    assert_eq!(file_kind(&p("a.HTML"), b"<p>", false), FileKind::Html);
    assert_eq!(file_kind(&p("a.md"), b"# hi", false), FileKind::Markdown);
    assert_eq!(file_kind(&p("a.svg"), b"<svg", false), FileKind::Svg);
    assert_eq!(file_kind(&p("a.png"), b"\x89PNG", false), FileKind::Image);
    assert_eq!(file_kind(&p("a.pdf"), b"%PDF", false), FileKind::Pdf);
    assert_eq!(file_kind(&p("main.rs"), "fn ü() {}".as_bytes(), false), FileKind::Text);
    assert_eq!(file_kind(&p("Makefile"), b"all:\n", false), FileKind::Text);
    assert_eq!(file_kind(&p("a.bin"), b"ab\0cd", false), FileKind::Binary);
    assert_eq!(file_kind(&p("a.bin"), b"\xff\xfe", false), FileKind::Binary);

    assert_eq!(file_kind(&p("a.txt"), &"ü".as_bytes()[..1], false), FileKind::Text);

fn version_and_eol() {
```

### Task 3: `PUT /api/files` with conflict detection and atomic save

**Files:**
- Modify: `src/main.rs`

**Interfaces:**
- Consumes: `version_of` and `TEXT_LIMIT_BYTES` (Task 1).
- Produces:
  - `#[derive(Deserialize)] struct SaveFile { path: String, content: String, version: String }`
  - `enum SaveError { Conflict(String), TooLarge, Io(std::io::Error) }`. `Conflict` carries the current version.
  - `fn save_file(path: &Path, content: &[u8], expected: &str) -> Result<String, SaveError>`. The algorithm:
    1. Canonicalise.
    2. Compare `version_of` with `expected` (a mismatch → `Conflict`).
    3. Write `.<name>.tabsh-<random_hex(6)>` in the same directory.
    4. `sync_all`.
    5. `set_permissions` from the original file's metadata.
    6. `rename` over the canonical path.
    7. Return the new version.

    On an error after step 3, remove the temporary file.
  - Route `/api/files` gets `.put(save)`, with `DefaultBodyLimit::max(4 * TEXT_LIMIT_BYTES as usize)` on that method router, because JSON escaping can grow the body.
  - Responses:
    - `204`, with header `x-tabsh-version: <new>` and `access-control-expose-headers: x-tabsh-version`;
    - `409` with body `{"version": "<current>"}`;
    - `413` when the content is larger than `TEXT_LIMIT_BYTES`;
    - `404` when the path is gone; `403` when permission is denied.

**Interfaces:**
- Produces:

```ts
export interface Found { kind: 'url' | 'path'; start: number; end: number; text: string; line?: number; col?: number }
export function findLinks(text: string): Found[]
```

  `start`/`end` are UTF-16 offsets into `text`, with `end` exclusive. For paths, `text` excludes the `:line:col` suffix, but `start`/`end` include it. The rules are in spec §1: URLs first, then path runs `[\w.~@+/-]+(?::\d+(?::\d+)?)?` that don't overlap a URL, accepted when they contain `/`, aren't only slashes, and contain a letter, or are a bare `name.ext` (name starts with a letter, extension 1–8 characters with a letter). A trailing `.` is stripped.

```ts
export interface FileInfo { path: string; kind: Kind; size: number; version: string; content?: string; eol?: 'crlf' | 'lf' }
export type Fetcher = (path: string, init?: RequestInit) => Promise<Response>; // the page's daemonFetch
export class FileError extends Error { constructor(public status: number, message: string) }
// ↑ write it without a parameter property (type stripping): declare `status: number;` and assign it.
export function filesUrl(session: string, path: string): string;   // `/api/files?session=…&path=…`, both encodeURIComponent
export function exists(f: Fetcher, session: string, path: string): Promise<boolean>;  // HEAD, true on 200
export function readFile(f: Fetcher, session: string, path: string): Promise<FileInfo>;
export function rawBlobUrl(f: Fetcher, absPath: string): Promise<string>;              // URL.createObjectURL of /api/files/raw
export function saveFile(f: Fetcher, path: string, content: string, version: string): Promise<{ version: string } | { conflict: string }>;
export function fromDisk(text: string): string;                    // \r\n → \n
export function toDisk(text: string, eol: 'crlf' | 'lf'): string;  // \n → \r\n when crlf
export function editorUrl(scheme: 'vscode' | 'cursor' | 'zed', absPath: string, line?: number, col?: number): string;
// `${scheme}://file${absPath}:${line ?? 1}:${col ?? 1}`, with each path segment encodeURIComponent'd
export function displayPath(absPath: string, base: string | undefined): string; // relative to base when inside it, else absolute
export function formatSize(bytes: number): string;                 // "812 B", "3.2 KB", "60 MB" (1024-based, 1 decimal under 10)
```
