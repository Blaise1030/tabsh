# Product Hunt submission

Everything below is in the order Product Hunt asks for it. Keep this file open
while you fill the draft.

## Before you submit

- [ ] `https://tabsh.cc` serves the new landing page (not the old "your terminal,
      in a browser tab" page).
- [ ] `https://tabsh.cc/og.png` is the new 1200 × 630 card and the preview looks
      right in a private window.
- [ ] The release you are launching is published, and the install command on a
      clean machine gets that version.
- [ ] The demo works on a phone, logged out, with no daemon.
- [ ] Your Product Hunt profile has a photo, a short bio and your X/GitHub links.
- [ ] You are the maker on the listing (not a hunter), unless a hunter is
      actually helping.

## Listing fields

**Name:** tabsh

**Tagline:** Your shells and agents, one calm scroll

**Description:** (253 chars)

> tabsh puts your terminal and coding agents in a browser tab. A small Rust
> daemon runs your shells locally; a board moves each card to In progress, Needs
> input or Completed as its agent works. Free, open source, macOS and Linux.
> Nothing leaves localhost.

**Topics:** Developer Tools, AI Coding Agents, AI Code Editors, Open Source,
Productivity

**Pricing:** Free

**Links:**

- Website: `https://tabsh.cc`
- GitHub: `https://github.com/Blaise1030/tabsh`
- Demo: `https://tabsh.cc/demo/?view=board&layout=list&drawer=1`

**Launch tags:** GitHub, Open Source, Developer Tools

**Promo code:** none. Do not invent one.

**Gallery:** upload in this order:
`01-hero.png`, `02-one-list.png`, `03-agents.png`, `04-board.png`,
`05-hooks.png`, `06-providers.png` (all 1270 × 760).

**Thumbnail:** `icon-240.png`.

**Video:** the YouTube link for `tabsh-demo.webm`. If the video isn't uploaded
yet, leave the field empty rather than shipping a broken link; the gallery

**Makers:** Blaise Tiong. Add only people who actually worked on it.

**Shoutouts:** optional. Only real people who tested or helped; no invented
names, no "the Claude Code team" unless they helped.

**First comment:** paste the comment from `01-copy.md`. Post it immediately
after submitting, then pin it.

## After submitting

- Open the live listing in a private window, on desktop and phone.
- Check that the cover image is `01-hero.png`, not a later upload.
- Check that the first comment is pinned and renders the install code block.
- Copy the live URL into the X thread draft, HN body and Reddit posts before
  posting them.
- Do not edit the tagline or description after the first hour unless there is a
  typo or a factual error.
